# USDC listing logo

The PNG and SVG are unmodified USDC token logos supplied by Circle.
Upload `usdc.png` in Plugin Builder's Logo field. The SVG is included as the vector original.

Source: [Circle official brand kit](https://www.circle.com/pressroom#brand-kit).
